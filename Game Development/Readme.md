### ✨About the Project

This is my first game development project using Unity. Technically, the game is a continuation of my animation project featuring an aristocrat who got lost in the desert. This time, he has ended up in a sandy labyrinth and must find a way out.

### 📑My Responsibilities
- Create scene and world
- Add character and fix camera to it
- Add scripts for characters movements 
- Make a main and settings menus with working buttons
- Create win/lose scense
- Make a maze map and add traps
- Add the key
- Add a script for door that can open only when you have key
- Make a timer for the duration of the playback


### 🎮Gameplay
- Third-person player movement
- Key collection and door interaction
- Interaction system
- Main menu and settings
- Win and lose conditions
- Background music and volume controls
- Map activation option
